Part 1

📘 VS Code & Workflow Cheat Sheet

Use Copilot as a collaborator across editing, debugging, code discovery, and daily development work.

🎯 What You'll Learn

−
  • Move beyond autocomplete and use Copilot as a collaborator.
  • Use chat participants, slash commands, and context variables for power-user workflows.
  • Use Copilot CLI in the terminal for shell, git, and troubleshooting help.
  • Apply real-world patterns for building, debugging, and explaining code and errors.

💻 Copilot in VS Code VS Code only

−

Ways to Interact

Mode Trigger Best For
Inline suggestions Just start typing Fast code completion
Inline Chat Ctrl+I / Cmd+I Quick edits and refactors in place
Chat view Ctrl+Alt+I / Cmd+Ctrl+I Multi-turn conversations, planning, explaining
Copilot Edits Ctrl+Shift+I Multi-file coordinated changes
Agent mode Chat view → Agent Autonomous multi-step tasks

Chat Participants (@)

Participant What it does Example
@workspace Knows about your entire project @workspace where is auth handled?
@vscode Knows VS Code features and settings @vscode how do I change my theme?
@terminal Knows your terminal and shell @terminal /explain
@github Queries GitHub issues, PRs, and repos @github show me my open PRs
The gem most teams miss: run a command in the integrated terminal, then ask @terminal /explain to get the flags, side effects, and safer alternatives.

Slash Commands (/)

Command Purpose
/explain Explain the selected code or command
/fix Propose a fix for the selection or diagnostic
/tests Generate unit tests for the selection
/doc Generate documentation or comments
/new Scaffold a new project or file
/newNotebook Create a new Jupyter notebook
/clear Reset the chat context
Heads up: VS Code chat slash commands are not the same list as Copilot CLI slash commands — see CLI slash commands for the terminal set.
Combine participants and slash commands: @workspace /explain how does the login flow work end to end? @terminal /explain @workspace /tests for src/services/pipeline.py

Context Variables (#)

Variable Purpose
#file Reference a specific file
#selection Current editor selection
#editor Currently active editor
#terminalLastCommand The last command you ran
#terminalSelection Highlighted terminal output
#codebase Broader codebase search
#problems Current diagnostics / problems panel
#changes Uncommitted git changes
Example prompts: /fix #problems Explain #terminalLastCommand and why it failed Refactor #selection to use async/await Summarize #changes for a commit message

Edits vs. Agent Mode:

  • Copilot Edits = coordinated changes across files you choose, with inline diff review.
  • Agent mode = give a goal, and Copilot plans, edits, runs commands, and iterates until done.

🛠️ Troubleshooting Workflows

−

Explain a Failing Terminal Command VS Code only

@terminal /explain # Copilot reads the last command and its output

Fix an Error from the Problems Panel VS Code only

/fix #problems

Understand a Stack Trace VS Code only

@workspace explain #terminalSelection and point me to the file most likely responsible

Debug with the Debugger VS Code only

why is variable X null here? # Ask in inline chat while paused on a breakpoint

Turn Changes into a Commit Message

Write a conventional commit message for #changes copilot -p "Write a conventional commit message for my staged changes"

Understand an Unfamiliar Codebase Quickly

@workspace give me a tour of this repo — entry points, main modules, and how data flows @workspace where is <feature> implemented?

🧠 Prompt Patterns That Work

−

Role + Goal + Constraints

You are a senior Python engineer. Refactor #selection to use dataclasses. Keep the public API unchanged and add type hints. Do not add new dependencies.

Ask for a Plan Before Code

@workspace outline the steps to add JWT auth to this API. Don't write code yet — just the plan and files that will change. # Then follow up with: Great — implement step 1.

Generate Tests First

/tests for #file:src/services/pipeline.py covering happy path, empty input, and network failure.

Explain Then Modify

/explain #selection Now rewrite it to stream results instead of buffering.

Use #codebase for Cross-File Reasoning

#codebase where do we validate customer IDs, and is the logic consistent everywhere?

✅ Discovery Cheat Sheet

−

Things worth trying today:

  • Run @terminal /explain after any command you don't fully understand.
  • Try /fix #problems on the next red squiggle you see.
  • Ask @workspace for a tour of the repo you joined most recently.
  • Ask Copilot to write your next commit message from #changes.
  • Install Copilot CLI and try copilot -p "..." for a quick lookup.
  • Try Agent mode on a small task, such as adding a CI status badge to the README.
  • Use /tests on a function that has no tests.
  • Ask @vscode how to configure something in the editor instead of searching the web.

🤝 Tips, Gotchas, and Etiquette

−
1
Context is king. The more relevant files and selections you add, the better the answer.
2
Iterate — don't restart. Follow-up prompts are cheaper and better than starting fresh.
3
Verify before you run. Read a suggested command, or ask Copilot to explain it first.
4
Don't paste secrets. Redact tokens, connection strings, and PII before prompting.
5
Use /clear. Reset stale context when you switch topics.
6
Keyboard shortcuts pay off. Ctrl+I (inline chat) and Ctrl+Alt+I (chat view) are the two to memorize first.

⚡ Copilot CLI Cheat Sheet

Quick reference for installation, commands, shortcuts, flags, agents, MCP, recipes, and troubleshooting in the terminal.

⌨️ CLI Overview CLI only

−

Copilot CLI brings Copilot to the terminal — no editor required. It is ideal for scripting, ops work, git help, and quick "what does this command do?" moments.

Tool Command Best For
Copilot CLI copilot Agentic sessions that read and edit your repo
gh copilot suggest gh copilot suggest -t git "undo my last commit but keep changes staged" Getting a shell, git, or gh command suggested
gh copilot explain gh copilot explain "git rebase -i --autosquash HEAD~5" Understanding a command before you run it
Shell aliases: add ghcs / ghce with gh copilot alias -- bash >> ~/.bashrc (or the zsh / pwsh equivalent).

📦 Installation CLI only

−
Platform Command
npm (all platforms) npm install -g @github/copilot
WinGet (Windows) winget install GitHub.Copilot
Homebrew (macOS/Linux) brew install copilot-cli
Install Script (macOS/Linux) curl -fsSL https://gh.io/copilot-install | bash
Verify installation: copilot --version

🔐 Authentication CLI only

−
Command Description
copilot login Authenticate via browser-based device code flow
copilot login --host HOST Authenticate to a specific GitHub Enterprise instance
copilot logout Sign out and remove stored credentials
Alternative: Set a fine-grained PAT with Copilot Requests permission: export GH_TOKEN=your_token_here

🎮 Modes of Operation CLI only

−
Mode How to Start Description
Interactive copilot Full conversation — explore, iterate, and build
Programmatic copilot -p "prompt" One-shot prompt — get an answer and exit
Autopilot copilot --autopilot Fully autonomous mode
Agent Mode copilot --agent=NAME Use a specific custom agent
Switch modes during a session: Press Shift+Tab to cycle:
Interactive → Plan → Autopilot → Interactive

🔧 Command-Line Flags CLI only

−
Flag Description
-p "prompt" / --prompt Run in non-interactive (programmatic) mode
--agent=NAME Select a specific custom agent
--model=MODEL Override the AI model (e.g., gpt-4)
--autopilot Enable autonomous mode
--yolo / --allow-all Enable all permissions (use with caution!)
--experimental Enable experimental features
--no-experimental Explicitly disable experimental features
--continue Resume your most recent session
--resume Choose from a list of previous sessions
--max-autopilot-continues N Limit autopilot continuation cycles
--config-dir PATH Use a custom configuration directory
--output-format FORMAT Specify output format (json, markdown)
--share Share session context externally
--acp Start as Agent Client Protocol server
Example — Autonomous mode with agent: copilot --agent=architect --autopilot --yolo -p "Design a microservices API"

🔤 Special Prefixes CLI only

−
Prefix Purpose Example
@ Include file contents in prompt @src/Program.cs Explain this file
! Run shell command (bypasses AI) !git status
& Shortcut for /delegate & complete the API tests

Quick Mental Model:

  • @ = "Hey Copilot, look at this file"
  • ! = "Hey terminal, run this command"
  • & = "Hey GitHub, take this task and run with it"

−

Custom agents are specialized AI personas defined in .github/agents/.

Example Agents:

🏗️ blueprint / architect System architecture & design
🔨 forge / developer Code implementation

📚 sage / doc-writer Documentation generation

⚡ CLI Power Tips CLI only

−
1
Batch context loading: Reference multiple files at once: @src/models/User.cs @src/models/Task.cs Compare these models
2
Context management: When your context fills up, use /compact to summarize and free space.
3
Tab completion: Type @ then start typing a file path — use Tab to autocomplete.
4
Escape hatch: Use ! for quick shell commands without leaving your conversation.
5
Trust once: Choose "Yes, and remember this folder" to skip the trust prompt next time.
6
Model switching: Use /model to balance speed vs. capability based on task complexity.
7
Session export: Use /share to save design discussions as markdown for team review.

🪙 Token Optimization

−

Token optimization means giving Copilot enough relevant context to help, without noisy oversized prompts that burn through the context window.

Practice Why it helps
Start narrow Attach the smallest useful file, selection, or error before expanding to broader codebase context
Summarize long output Paste only the failing section or stack trace instead of full logs
State explicit goals Task, constraints, and desired output mean fewer turns spent inferring intent
Reset stale context Use /clear for topic changes and /compact to summarize long sessions
Prefer references over copies Use #file in VS Code or @path/to/file in the CLI instead of pasting whole documents
Ask for a plan first A plan surfaces missing context before tokens are spent going the wrong direction
Efficient prompt pattern: Goal: fix the failing auth test. Context: #problems and the auth test only. Constraint: do not change the public API. First explain likely causes, then propose the smallest fix.

🆘 CLI Troubleshooting CLI only

−
Issue Solution
copilot: command not found Ensure npm global bin is in PATH: npm bin -g
Custom agents not appearing Run from repo root, check .github/agents/ exists
MCP server not connecting Verify Node.js 22+, check JSON config syntax
Session context full Run /compact to summarize and free space
Authentication expired Run /login or copilot login
